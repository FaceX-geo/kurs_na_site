Курс на Север

Единая система визуальных и UX-правил для всех экранов платформы. Этот документ — источник истины для дизайнеров, frontend и backend команды.

1. Бренд-платформа

Характер: уверенный, чистый, современный. Визуальный язык: editorial-подача, строгая сетка, много воздуха, холодный акцент, функциональный motion.

Clarity

Контент строится в понятной иерархии: headline, тезис, действие.

Trust

Коммуникация фактичная, без визуального шума и скрытых условий.

Human UX

Любой сценарий должен завершаться за 1–2 шага без перегрузки.

Arctic Tone

Монохромная база + холодный акцент как отличительная черта платформы.

3. Типографика

Self-host шрифты без CDN-зависимости: `Onest Local` + `Manrope Local`.

Display family

Карьерный маршрут в Арктику

Шрифт: --font-display, веса 500–800, плотный трекинг для обложечного эффекта.

Body family

Проект сопровождает участника от заявки до переезда, трудоустройства и адаптации в регионе.

Шрифт: --font-body, веса 400–600, повышенная читаемость на мобильных.

4. Motion guide (premium subtle)

Анимации применяются только для иерархии и обратной связи, без декоративной перегрузки.

Fast · 120mshover states, focus rings
Base · 180msbutton transitions, chips
Slow · 260mscard transform, small reveals
Linger · 420mssection reveal, hero settle

Do

  • Анимируйте только opacity/transform.
  • Подчеркивайте переход между блоками при скролле.
  • Используйте мягкие easing-кривые.
  • Поддерживайте prefers-reduced-motion.

Don't

  • Не используйте бесконечные декоративные циклы.
  • Не делайте резких scale/rotate анимаций.
  • Не скрывайте критичный контент до JS-init.
  • Не используйте motion дольше 500ms для обычных действий.

8. Release checklist

Контроль перед публикацией главной страницы.

  • Шрифты загружаются локально из assets/fonts (без обязательного CDN).
  • Токены в styles/main.css и styles/brand.css синхронизированы.
  • Контент видим без JS; reveal запускается только при .is-pending.
  • prefers-reduced-motion отключает несущественные анимации.
  • Контраст, фокус и клавиатурная навигация соответствуют a11y-базе.
  • Семантика legacy-контента сохранена в новой IA без потери ключевых фактов.
  • Модалки: фокус-трап, закрытие по ESC и overlay, возврат фокуса к триггеру.
  • Форма: field-level ошибки для 422, глобальный статус с requestId.
  • Fallback словаря сфер работает при недоступном /dictionaries/spheres.
  • Мобильное меню корректно работает на touch/keyboard сценариях.
