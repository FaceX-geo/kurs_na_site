# Интерактивная карта Мурманской области

## Цель

Декоративный рельеф и координаты разделены. Изображение отвечает только за визуальный стиль, а положение городов рассчитывается по полной геометрии суши Мурманской области. Административная relation OpenStreetMap `2099216` используется как справочный контур территории, а snap выполняется по береговой геометрии без территориальных вод.

## Источники

- Геометрия суши и островов: `assets/data/murmansk-land.geojson`
- Крупнейшие озёра: `assets/data/murmansk-waterbodies.geojson`
- Проекция: `assets/data/murmansk-map-projection.json`
- Точный SVG-контур: `assets/maps/murmansk-oblast.svg`
- Декоративный рельеф: `assets/images/murmansk-oblast-relief-v3.webp`
- Локальный пустой fallback: `assets/data/map-points.json`

## Контракт публичного API

`GET /api/v1/map-points`

```json
{
  "items": [
    {
      "id": "murmansk",
      "name": "Мурманск",
      "longitude": 33.07497,
      "latitude": 68.970665,
      "eyebrow": "Столица региона",
      "description": "Краткий текст о городе.",
      "sectors": ["Логистика", "Городские сервисы"],
      "source": "https://example.org",
      "nudgeX": 0,
      "nudgeY": 0,
      "labelOffsetX": 18,
      "labelOffsetY": -34,
      "status": "published"
    }
  ]
}
```

Публичный endpoint отдаёт только `published`. `nudgeX` и `nudgeY` двигают визуальный pin, но не меняют сохранённые координаты и точку-якорь.

## Сценарий администратора

1. Администратор кликает по карте.
2. Клиент переводит пиксель клика в WGS84 через `unprojectMapPoint`.
3. Backend проверяет попадание в Polygon/MultiPolygon из `murmansk-land.geojson`.
4. Если клик вне суши, backend возвращает ближайшую точку границы и расстояние привязки.
5. Администратор подтверждает координаты, вводит текст и переводит запись из `draft` в `published`.
6. Публичный сайт получает точку через `/api/v1/map-points`.

## Правила целостности

- Источник истины: `longitude` и `latitude`, а не проценты или пиксели.
- Координаты хранятся в WGS84 с точностью минимум 6 знаков.
- Snap выполняется на backend по точному GeoJSON.
- Декоративное изображение можно менять без миграции точек, пока сохраняются проекция и aspect ratio `4:3`.
- Изменение версии геометрии требует новой версии projection contract и визуальной проверки опубликованных точек.
